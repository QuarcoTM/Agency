ДЕН И НОЩ — v1.52

НОВО: собствена анонимна статистика в админ панела.

ЕДНОКРАТНА НАСТРОЙКА В SUPABASE:
1. Влезте в Supabase проекта.
2. Отворете SQL Editor -> New query.
3. Отворете файла supabase-analytics-v1.52.sql от този пакет.
4. Копирайте целия SQL текст и натиснете Run.
5. Качете всички файлове от v1.52 върху сайта.
6. Отворете /admin/ -> Статистика -> Обнови.

Какво се отчита:
- преглеждания на страници;
- кликове върху телефонните номера;
- отваряния на страницата Контакти;
- отваряния на картата;
- отваряния на FAQ;
- входящ източник (Google, Facebook, директно, друг домейн);
- най-посещавани страници;
- графика по дни.

Поверителност:
Статистиката не създава cookie/localStorage visitor ID и не записва IP, user-agent, име, имейл или телефон на посетителя в analytics таблицата. Затова умишлено няма метрика „уникални посетители“.
