- плъзгането с пръст върху списъка с категории вече превърта, без да отваря категорията;
- категория се отваря само при кратко натискане без движение на пръста;
- продуктовите кодове са скрити от публичния каталог по подразбиране;

ЕДНОКРАТНА НАСТРОЙКА ЗА ИЗБОР НА ВИДИМИТЕ КОДОВЕ:
1. Влезте в Supabase проекта.
2. Отворете SQL Editor -> New query.
3. Отворете файла supabase-product-code-visibility-v1.61.sql от този пакет.
4. Копирайте целия SQL текст и натиснете Run.
5. В админ панела редактирайте продукт и включете „Показвай кода в сайта“ само когато искате кодът да се вижда.

Ако SQL настройката още не е пусната, сайтът продължава да работи и всички продуктови кодове остават скрити.
